# IELTS Study OS · 产品与实施清单

## 审查结果

原仓库只有 `feihe-final.pptx`，没有应用代码。保留原文件，新建独立的 Next.js 应用。

## 首版架构

- Next.js App Router + TypeScript；自有 CSS 设计系统（奶白、蓝灰、薄荷绿），响应式侧栏与移动导航。未引入未实际使用的 UI 框架。
- 本地优先：文本学习记录存 localStorage，录音与导入截图存 IndexedDB。首次使用没有伪造分数、学习记录或进步数据。
- 可选 Supabase 邮箱密码登录、RLS 隔离的状态同步与私有录音/截图存储。设备本地数据只有登录后明确同步才上传；切换账号不会自动上传上一人的本地数据。
- AI 为服务端 OpenAI-compatible 适配器；未配置/失败时提供明确标注的规则教学。规则反馈不声称理解所有语义、发音或给出雅思评分。AI 密钥只在服务端。
- 语音：MediaRecorder 真实录音、重录、回放；支持浏览器原生识别（浏览器支持与网络决定可用性），可手动确认/修改转写。系统 TTS 提供跟读示范。
- 数据导入：浏览器内英文 OCR + CSV/Excel，全部先预览确认再入库；重复练习保留独立记录，不连接爱听写未授权接口。原创示例，无复制剑桥题目。

## 阶段与验收

1. [x] 产品架构与高保真界面：10 个学习页面、设置与无数据状态，移动布局。
2. [x] 每日任务：300 分钟、任务细节、拆分、计时、暂停、完成/续学、错题记录、本地保存。
3. [x] 写作：五等级、造句到段落、讲解与示范、原稿/反馈/修改/独立重写留存，依据独立重写证据建议升级。
4. [x] 口语：五等级、原生录音、可选转写、文本反馈、跟读、复录对比，最多三个关键反馈，无短答分数。
5. [x] 数据：截图 OCR、CSV/Excel/手动录入、确认、来源与可信度、首次/重复及限时分析；原创阅读、听力闭环练习。
6. [x] 计划与报告：基于证据分配总计300分钟、困难降阶、续学与阶段门槛、周报和日历。
7. [ ] 长期迭代：授权考试题库与音频、专业发音评估、经校准的考试趋势预测、跨设备冲突合并。

第三方生产服务必须由站点所有者配置后验证；本机自动化不能证明 Supabase 项目、邮件投递、第三方AI、真实麦克风和移动浏览器识别已经可用。

## 教学数据约束

考试日 2026-12-31，起始日 2026-10-22。两个日期相差70天；训练第1天为10月22日，第70天为12月30日，12月31日为考试日。使用亚洲/上海日期边界。四阶段只是日程建议，写作/口语基础未达到门槛时不自动强推模考。

每个任务：目标、材料、说明、示范、练习、预计时间、完成标准、反馈、下一步。八步闭环贯穿教材。阅读/听力掌握度与首次限时成绩分开；从不把重复不限时成绩换算成考试分数。无证据时标记待诊断。

## 信息结构

Dashboard → 今日学习 → 科目教师 → 错题复练。独立导航：数据中心、70天路径、周报、设置。首页以开始一项可以完成的任务为主操作，展示真实计时、能力与下一步，而非虚构图表。

## 安全与隐私

本地模式无需账号；共享设备应在结束后导出并删除数据。浏览器语音识别可能由浏览器厂商远程处理，启用前告知。OCR 与录音文件在用户设备处理/存储；云同步需明确点击，私有 bucket + owner RLS。API 严格限定输入、认证、同源请求、超时与频率；未配置 Supabase 时生产环境禁用收费 AI 请求，保留本地教学。远程模型反馈视为文本显示。
