# 我的资料与雅思听说训练

## 先开始一次可完成的练习

首页 → **场景词与改写** → 播放一个词 → 自己拼写 → 保存 → 看讲解 → 换下一个词。太难时先打开示范，本次会保留为有支架练习。复习按1/3/7天安排，错误优先；不把记住一个词当成正式考试水平。

三份用户提供的PDF共98页，已转为2,955个带文件名和页码的检索索引。其中105个场景词、44组限定语境改写、26个连接与基础表达共175条已核对，默认可训练。其余2,780条保留为候选，需核对后加入训练。`rarely`与`never`、`professional`与`happy`等不能机械等同；词表中的错误及歧义不作为训练答案。词表年份不构成2026年押题保证。

原PDF不在公开源码中。想对照全文时，到**我的学习资源**主动选择原PDF，核对后保存。文件和全文保存在当前浏览器IndexedDB；网站不能直接浏览整台电脑。导入的双语词条默认待核对，避免把OCR或排版错误作为正确答案。

## 爱听写在网页里，怎么接入

网站不能直接读取另一个网站的登录记录。打开自己的爱听写练习历史，截图后在**爱听写数据中心**上传，核对材料编号、首次/重复、是否限时、题数、耗时、播放次数。平台提供导出时可用CSV/XLSX导入；没有导出时用截图或手工填写。同一篇做两次保留两条。

自己已经合法持有的PDF、DOCX、文本或音频，可在**我的学习资源**选择文件或文件夹导入。每批最多100文件/100MB，单文件≤15MB；重复文件按SHA-256去重，不覆盖练习历史。扫描PDF会提示没有文本，可改用清晰图片OCR；当前OCR以英文数字为主，需要人工核对。DOCX只提取正文，不运行宏、链接或嵌入内容。

听力页 → **我的真实音频**：选择已导入音频，设置A/B起止秒数，逐句循环；首次答案、复听修正和播放/循环次数保存。音频不会被伪造为已有转写或自动正确题数。

要按题评分，可下载资源页的JSON模板，填写自己有权使用的题目、原文、答案、字数限制、定位句和改写说明。导入后核对答案键，绑定自己导入的音频，再进入练习。导入JSON中的外部音频地址不被采纳。本站不下载爱听写的付费音频或读取其未授权接口。

## 更接近雅思考试的听说方式

- 听力内置4组原创专项、16题，覆盖Part 1表格、Part 2地图/选择、Part 3讨论/匹配、Part 4讲座笔记。先预读再听，作答后显示证据、改写和干扰信息；可请求教师讲解。AI未配置时使用明确标注的离线讲解。
- 精听允许回放和原文；单次检测隐藏暂停拖动及作答前原文。提前提交、刷新、中断、拖动、重复材料或看过原文，都不作为完整的新材料单播证据。每次作答独立保存，不推算分数。
- 口语有6类熟悉话题、42个原创问题/提示卡，区分Part 1直接回答、Part 2提示卡组织、Part 3观点解释。基础等级先示范一句；较高等级增加原因或细节，每题示范回应本题。
- Part 2计时训练先准备1分钟，再开始最长2分钟录音；关键词笔记与当前问题草稿保存。分步教学可以只练一句，无需直接完成长答。
- 系统英式英语语音可用时优先使用；没有系统语音时使用本站预制合成提问和示范。合成声音不冒充真实考官、真题录音或自然发音评估，真实原声资料可主动导入。
- 录音、回放、转写核对、最多3个问题反馈、跟读和复录沿用保存流程。仅有转写时，发音和声学流利度标记为未评估。浏览器语音识别可选，可能依赖厂商联网服务；不支持时可自己填入转写。

这些是分部专项训练，并非完整正式模考或官方口语评分。周报分别汇总词汇尝试、无提示单播答对和听力练习条件；300分钟计划仍保留90/75/60/60/15分钟的初期配比。

## 九分学长与网上资料

用户目前没有九分学长资料，资源库不会预填不存在的文件。当前云环境的网页搜索及相关站点访问被代理403阻断，尚未核验官方公开入口或样题。本次没有获得或导入其题库。资源页保留待核验状态，另提供IELTS官方Academic样题的已知入口，但本环境未完成页面可用性核验。网上搜索恢复后仍应核对发布者、访问许可和适用年份，不把网盘转载、付费题库或“2026必考”营销当作可靠来源。

## 备份、云端和维护

设置 → 导出完整备份：包含学习状态、录音、截图、私人资源原文件及提取文本。更换网站地址、清理浏览器或重建Codespace前先导出；备份含私人文件，请自行妥善保管。旧版备份会自动补齐新增字段。

云同步仍需配置自己的Supabase；新安装使用`supabase/schema.sql`。已有项目需另执行`supabase/migrations/20261022_personal_resources.sql`，增加私有桶支持的资料MIME，保留Private与用户隔离策略。本次未对用户真实Supabase项目执行迁移或验证云同步。

依赖更新后执行`npm ci`、`npm run prepare:ocr`并重启服务；准备脚本会同时复制本站OCR和PDF worker，不需要外部CDN。合成音频已随源码提供，运行网站不需要ffmpeg。维护者需要重生成时运行`node scripts/generate-personal-audio.mjs`，要求ffmpeg含flite；只生成原创练习和公共词语的声音。
